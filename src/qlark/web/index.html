对话行为

随「应用」一起提交 即时生效，不需要重启 NapCat
群聊引用原消息 仅影响群聊，私聊不受影响。群里引用会让消息看着比较吵，默认关闭
消息带上昵称与时间 群聊里所有人共用一份记忆，不带昵称的话机器人分不清哪句是谁说的，会把 A 的偏好记到 B 头上；时间让它知道「早上好」是几点的早上好。群聊和私聊都生效
表情包目录
散放「生气.png」这种文件即可，文件名就是情绪；也可以建子文件夹，一个情绪放多张时会随机挑一张
回复判断表 **不是掷骰子，是让模型自己看情境**：打招呼就简短回，问事实就直答，对方在情绪里就认真回、不许敷衍，开玩笑就只接一个梗。同时约束「一次只说一件事、不超过三句」
语音回复 **要不要发由模型自己判断**，没有概率。只有很短、而且用声音说出来更自然的那几句才会走语音。还需要在「人设配置」里给角色勾上并写音色描述
私聊出错时告知原因 关闭后只写日志，不向对方回复
与模型 API 使用同一个保存接口，一起提交
每个人设的记忆是独立的；每个群 / 每个人各自记住自己当前用的人设。

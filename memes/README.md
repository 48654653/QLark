# 表情包素材放这里

QLark 的「表情包回复」会从这个目录随机挑图发给对方。**图片本身不随仓库提供**，
请自己找图放进来——这些是角色美术素材，版权不在本项目，所以公开仓库只留这份说明。

## 怎么放

两种都行：

```
memes/
├── 嫌弃.png          ← 散放：文件名就是情绪名
├── 害羞.png
└── 开心/             ← 或者建子文件夹，一个情绪放多张时随机挑一张
    ├── 1.png
    └── 2.png
```

支持 `png / jpg / jpeg / gif / webp / bmp`。

## 情绪名怎么起

情绪名就是文件名（或文件夹名）。开启表情回复时，QLark 会把当前目录里的情绪名
列进提示词，让模型从中挑一个最贴合的 —— 所以**名字起得越像语气，挑得越准**。

| 推荐 | 不推荐 |
|---|---|
| 嫌弃、害羞、求饶、给心心 | 猫、狗、电脑 |
| 打你、蜷缩、馋、哭哭 | 第一张、待用 |

原因：「嫌弃」几乎任何一句话都能配上，而「猫」只有聊到猫的时候才用得上。

## 目录在哪配

界面「模型配置 → 对话行为 → 表情包目录」。留空就用**程序目录下的 `memes/`**。

## 数量

10～30 个情绪就够。太多会让模型挑不准，也会把提示词撑长。
